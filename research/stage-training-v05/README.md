# CPBL 分段模型實際訓練 v0.5（研究版）

2026-11-21。已執行訓練與開發測試，未替換正式 SP 引擎。

## 這次建立了什麼

1. 單一追蹤投球產生強勁公平擊球的機率：強勁操作定義為 EV ≥ 150 km/h。非場內擊球保留為負例；缺少公平擊球標籤的球排除。這不是總失分風險。
2. 已形成公平擊球時，強擊機率，以及初速／仰角／方向的條件式平均預測。
3. 已知擊球條件時，擊球出局分支的機率。標籤為事件分支，尚非已核實的個人接球／打者出局責任。

## 校準與缺失風險

單球強擊平均預測 6.55%，實際 5.23%，仍高估。十等寬分箱ECE 0.0132；原始校準表保存於metrics，不在測試集重擬合校準器。
公平擊球條件下的強擊預測平均33.86%、實際27.71%，偏差更大，不能直接當責任真值。
缺少完整落點欄位的開發測試樣本，出局比例97.78%，完整欄位為62.20%，顯示量測缺失與結果相關。
因此補做固定參數完整案例敏感度分析：同樣4,452筆中，只用初速／仰角／方向等的Log Loss 0.447904，再加落點／滯空時間為 0.400674。這是選擇性完整案例，仍不證明因果守備能力。

## 防洩漏與特徵

投球模型只用壘況／出局數、投球前球數、凍結打者歷史、進壘x/z、球速、轉速、出手高度／側向／延伸。未加入球種分類或左右投打，尚無獨立投手歷史效果。
實際初速、仰角、方向、場內球標籤、打席終結結果與事後球數不進投球模型。
打者歷史只由合格訓練期擊球建立；訓練期逐日前綴，驗證與測試固定6月底歷史。30偽樣本的聯盟先驗由訓練區塊估計。
訓練／驗證／測試比賽ID互不重疊，pitch_id唯一。Scaler與缺值填補只fit訓練資料。樹模型原生處理缺值。

## 選模與可重現

機率模型比較logistic及140棵、葉數7/15的HistGradientBoosting；僅依驗證Log Loss選擇。回歸依驗證MAE。seed184、CPU四執行緒、early stopping關閉。沒有因測試結果重新選超參數。
套件為Python 3.14.6、scikit-learn 1.9.0；joblib載入只使用可信的本包權重。portable JSON是純數值樹，六個主要模型各100筆與sklearn預測一致（最大誤差0）。Infinity閾值用字串保存。

```powershell
python train_stage_models.py --data <建模包/data> --output results
python train_pitch_risk.py --data <建模包/data> --output results --site-source <網站/index.html>
python audit_training_missingness.py --data <建模包/data> --output results
```
